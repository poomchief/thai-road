# ไทยเดินทาง

เว็บวางเส้นทางทั่วประเทศไทย เตือนฝนตกหนักและความเสี่ยงน้ำท่วมตลอดเส้นทาง มีพยากรณ์อากาศ 5 วัน แนะนำที่พักระหว่างทาง และนำทางด้วย GPS ของโทรศัพท์

เป็นเว็บแบบ static ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล ไม่มีข้อมูลจำลอง ส่วนข้อมูลจราจรเรียลไทม์ใช้ API key ฟรีของ TomTom ที่ผู้ใช้วางในหน้าเว็บเอง (เก็บในเครื่อง ไม่อยู่ในโค้ด)

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ |
| `style.css` | หน้าตา (รองรับโหมดมืดและมือถือ) |
| `app.js` | การทำงานทั้งหมด |
| `data.js` | รายชื่อเมืองและทางหลวงหลัก ใช้เป็นตัวเลือกด่วนและเส้นทางสำรอง |
| `vendor/` | Leaflet 1.9.4 (ไลบรารีแผนที่) |

## แหล่งข้อมูล

| ส่วน | แหล่งที่มา | ข้อมูลจริงหรือจำลอง |
|---|---|---|
| แผนที่ถนน (ชื่อภาษาไทย และแบบละเอียดสูงสำหรับจอ retina) | OpenStreetMap | จริง |
| ภาพดาวเทียม | Esri World Imagery | จริง (ใช้ได้ฟรีสำหรับงานไม่เชิงพาณิชย์) |
| แผนที่ภูมิประเทศ | OpenTopoMap | จริง |
| ค้นหาสถานที่ | Nominatim (OpenStreetMap) | จริง |
| เส้นทาง | OSRM (router.project-osrm.org) | จริง ถ้าใช้ไม่ได้จะใช้ทางหลวงหลักโดยประมาณแทน |
| พยากรณ์อากาศ ฝนรายชั่วโมง | Open-Meteo | จริง |
| ความเสี่ยงน้ำท่วม | คำนวณจากฝนพยากรณ์ของ Open-Meteo (ฝนสะสม 50 มม./วันขึ้นไป) | ประเมินจากฝนจริง แต่ไม่ใช่รายงานน้ำท่วมจริง |
| เรดาร์ฝน | RainViewer | จริง |
| ที่พักใกล้จุดพัก | OpenStreetMap (Overpass) | จริง |
| ที่พักใกล้ฉัน | OpenStreetMap (Overpass) + ลิงก์ราคาคืนนี้ไป Agoda / Booking.com / Google Maps | รายชื่อจริง ราคาดูที่เว็บจอง (เว็บนี้ไม่ได้ดึงราคามาแสดงเอง) |
| ตำแหน่งปัจจุบัน | GPS ของอุปกรณ์ | จริง (ต้องเปิดผ่าน https) |
| อุบัติเหตุ รถติด ถนนปิด ซ่อมถนน น้ำท่วม (รายงานจริง) | TomTom Traffic (อัปเดตทุก 3 นาที) | จริง ต้องใส่ API key ฟรีของ TomTom |
| เส้นทางที่คิดสภาพรถติด | TomTom Routing | จริง เมื่อใส่ key (ไม่มี key ใช้ OSRM ซึ่งไม่คิดรถติด) |
| เส้นสีสภาพการจราจร | TomTom Traffic Flow | จริง เมื่อใส่ key |

ตำแหน่งบ้านเก็บไว้ในเบราว์เซอร์ของผู้ใช้แต่ละคน (localStorage) ไม่ถูกส่งไปที่ไหน

## นำขึ้นเว็บ

ต้องเปิดผ่าน **https** เท่านั้น ไม่อย่างนั้นเบราว์เซอร์จะไม่ให้ใช้ GPS ทั้งสองวิธีด้านล่างให้ https ฟรี

### วิธีที่ 1: Netlify Drop (ง่ายสุด ประมาณ 1 นาที)
1. เปิด https://app.netlify.com/drop
2. ลากโฟลเดอร์ `thai-road-web` (หรือไฟล์ `thai-road-web.zip` ที่แตกแล้ว) ไปวางในหน้านั้น
3. จะได้ลิงก์ เช่น `https://ชื่อสุ่ม.netlify.app` เปิดในมือถือได้ทันที
4. ถ้าอยากให้ลิงก์อยู่ถาวรและเปลี่ยนชื่อได้ ให้สมัครบัญชี Netlify ฟรี แล้วกด Claim

### วิธีที่ 2: GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ไปที่ Settings → Pages → Source เลือก `Deploy from a branch` → branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
3. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`

### ลองในเครื่องตัวเอง
```bash
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000 (GPS ใช้ได้บน localhost)

## ใช้บน iPad / iPhone
- เปิดลิงก์ใน Safari แล้วกดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** จะได้ไอคอน "ไทยเดินทาง" ที่เปิดแบบเต็มจอเหมือนแอป
- ครั้งแรกที่กดใช้ตำแหน่ง ให้กด **อนุญาต** ถ้าเคยกดไม่อนุญาตไว้ ให้ไปที่ การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → บริการหาตำแหน่ง → เว็บไซต์ Safari
- **iPad รุ่น Wi‑Fi ไม่มี GPS** ตำแหน่งจะคลาดเคลื่อนได้หลายกิโลเมตร ใช้ปักหมุดบ้านเองบนแผนที่ หรือเปิด Hotspot จากมือถือ ส่วน iPad รุ่น Cellular มี GPS ใช้นำทางได้ปกติ
- เสียงเตือน: เปิดสวิตช์ "เสียงเตือนภาษาไทย" ก่อนเริ่มนำทาง และปิดโหมดเงียบ
- หน้าจอไม่ดับระหว่างนำทางใน iPadOS 16.4 ขึ้นไป ถ้ารุ่นเก่ากว่าให้ตั้ง ล็อกอัตโนมัติ → ไม่ใช้

## ข้อควรรู้
- บริการ OSRM, Nominatim, OpenStreetMap tiles และ Overpass เป็นบริการสาธารณะฟรีสำหรับการใช้งานเบา ๆ ถ้าเว็บมีผู้ใช้มากควรเปลี่ยนไปใช้บริการแบบเสียเงินหรือตั้งเซิร์ฟเวอร์เอง
- ข้อมูลจราจรเรียลไทม์: สมัครฟรีที่ https://developer.tomtom.com/user/register คัดลอก API key แล้ววางในกล่อง "ข้อมูลจราจรเรียลไทม์" โควตาฟรีวันละ 2,500 ครั้ง (การโหลดเหตุบนถนนตามเส้นทาง 800 กม. ใช้ประมาณ 10–30 ครั้ง)
- ก่อนเดินทางจริงควรตรวจสอบกับกรมทางหลวง 1586 และ ปภ. 1784
